# Portfolio

Personal portfolio site built with React and Vite.

## Overview

Static/SPA portfolio showcasing projects and contact information. Uses Vite for development and production builds.

## Stack

- React
- Vite
- JavaScript

## Structure

```
src/           # Pages and components
public/        # Static assets
index.html
vite.config.js
```

## Getting started

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```
